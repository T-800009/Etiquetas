01 / Ambiente

Conexão ao Decepticon

Este painel não executa comandos, não faz varreduras e não transmite dados do laboratório. Ele abre o dashboard do Decepticon que estiver rodando no mesmo dispositivo.

Estado: não conectado ao backend. Para abrir o dashboard, o Decepticon precisa estar instalado e iniciado localmente, com a interface web ativa em http://localhost:3000. No celular, o endereço aponta para o próprio celular, não para seu PC.
01Docker

Prepare um ambiente Linux, Windows com Docker ou WSL2.

02Configuração

Siga as instruções oficiais e configure um provedor de IA.

03Dashboard

Inicie o Decepticon e habilite a interface web local.

04Acesso

Use o botão acima no navegador do computador.

Nenhuma credencial, token ou API externa é solicitada por esta página.
